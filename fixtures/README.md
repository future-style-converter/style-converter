# Fixtures

Test inputs for the converter and the visual pipeline: JSON envelopes
mapping component names to CSS properties (format: repo-root `README.md`
"Input format").

- `properties/<category>/<property>.json` — the canonical per-property
  suites, one directory per IR category (33 categories), one component
  per value variant. Long-tail categories use a single
  `properties/<category>/longtail.json` covering every property in the
  category (one component per value variant, zero `generic` rows).
- `components/` — realistic multi-property UI components (card, nav
  header, form input, …), consumed by the Tier 5 interaction and Tier 11
  a11y harnesses under `tools/visual/`.
- `combinations/` — interaction-class fixtures (blend × opacity, filter
  chain order, perspective × translateZ, transform-list order, radius ×
  overflow × transform, …). Each component carries an `_expect` **spec
  oracle** — the hand-computed value the CSS spec requires — so the run
  fails on a wrong-but-agreeing render, which SSIM alone cannot catch.
  See `combinations/README.md`.
- `fidelity/` — generated suites (per-category `*.combos.json`, plus
  `dynamic/` state + media + dark-mode, `motion/` keyframes and
  transitions, `pairwise/`, `placement/`, `tokens/`, `trees/`). Generated,
  not hand-authored: `fidelity/PROVENANCE.md` + `INPUTS.lock` record how.
- `_metric_probes/` — text-metrics probe fixtures for
  `tools/visual/probe-text-metrics.sh` (4x hi-res capture pipeline).
- `visual-test.json` — the 109-component (327 platform-pair) baseline
  fixture that `BASELINE=1 ./test-all.sh` gates against (109 components ×
  3 platforms = 327 captures/pairs; "327-component" was a wording error —
  retrospective A2#17).
- `visual-test-controls.json` — the control companion to `visual-test.json`
  (its baselines are part of the committed `tools/visual/baseline/` set).
- `composition-test.json` — the children/slot composition fixture.
- `wpt/` is a gitignored corpus tree regenerated by `tools/titan/fetch-wpt.sh`.

Convert one:

```bash
# from the repo root (JDK 21)
./gradlew :converter:run --args="convert --from css --to ir -i fixtures/visual-test.json -o out"
# → out/tmpOutput.json (the IR)
```

Render + compare it on all three platforms: `./test-all.sh fixtures/visual-test.json`.
